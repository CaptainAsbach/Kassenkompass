KassenKompass – PWA Phase 1

Enthalten: index.html (bestehende App mit PWA-Funktionen), manifest.webmanifest, sw.js und App-Symbole.

Einbau in GitHub: ZIP entpacken. Im Repository CaptainAsbach/Kassenkompass die vorhandene index.html ersetzen und manifest.webmanifest, sw.js sowie den Ordner icons im Hauptverzeichnis hochladen. Änderungen committen und warten, bis GitHub Pages aktualisiert ist. Danach die App einmal online öffnen, damit der Browser die Oberfläche zwischenspeichert.

Android: In Chrome ⋮ > „App installieren“ oder „Zum Startbildschirm hinzufügen“. iPhone: In Safari Teilen > „Zum Home-Bildschirm“.

Wichtig: Die Oberfläche kann offline starten. Microsoft-Anmeldung und OneDrive-Synchronisierung benötigen weiterhin Internet. Dies ist eine installierbare Web-App (PWA), keine native APK.
